This page prepares a launch command. It does not connect to or control a running game.


    
    
Get tools/trace-lab/capture.py from the repository. Replace its placeholder path and the game executable, then run the command in PowerShell from the converted game directory. Trace settings apply only to the launched process.

    
The 15-second window closes on the first present at least 15 seconds after it opens. The game continues. If it stalls or exits before that present, the trace may not be written. A manual trigger is checked at most once per 250 ms while waiting, and each launch captures once.

    
Recording has overhead. Default event buffers use about 10 MiB per queue worker, presenter or draw worker; the smaller option uses about 2.5 MiB and can drop more events. Other buffers and output formatting use additional memory. Buffers can remain allocated, and GPU timestamp overhead can continue outside the window. Relaunch with Off for an untraced run; Stop & unload affects this viewer only.

    
These views show elapsed time inside scopes, not measured CPU utilization. Nested or concurrent durations cannot be added to obtain a frame cost. Missing events do not establish idle time. The GPU track may omit batches at the end of the capture.

    
AnyPS5 has a live overlay on F10. This tool reads saved captures. RAM/VRAM usage charts require memory-usage data that is not available in the trace format supported here.

Record a short capture in AnyPS5

Run this in PowerShell from the converted game directory. Replace the executable name with the one for your game.

$env:APS5_TRACE_SECONDS = '30:10'
$env:APS5_PROFILE_GPU = '1'
$env:APS5_TRACE_DIR = (Join-Path $PWD 'trace-output')
New-Item -ItemType Directory -Force $env:APS5_TRACE_DIR
.\app.exe

This records a 10-second window starting 30 seconds after the first present. Open the trace and summary from the same run together. If the game exits before the window closes, no trace file is written.

For longer sessions, periodic summaries are available with APS5_TRACE_SUMMARY_EVERY=5. They do not contain individual thread events.

These views show elapsed time inside scopes, not measured CPU utilization. Nested or concurrent durations cannot be added to obtain a frame cost. Missing events do not establish idle time. The GPU track may omit batches at the end of the capture.

AnyPS5 has a live overlay on F10. This tool reads saved captures. RAM/VRAM usage charts require memory-usage data that is not available in the trace format supported here.
